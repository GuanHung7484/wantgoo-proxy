# 遊戲室 Online

這是一個手機版與網頁版通用的靜態前端遊戲入口。第一款遊戲為「麻將三缺一」，目前包含大廳、商城/儲值風格畫面、規則頁，以及麻將牌桌的基本互動原型。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 外網連接

若要讓外部網路可連線，需部署到公開主機。可選擇：

- Vercel / Netlify：建立新專案後上傳此資料夾，輸出目錄選專案根目錄。
- GitHub Pages：把檔案推到 GitHub repository，啟用 Pages。
- Cloudflare Tunnel：適合暫時把本機網站公開，但正式營運仍建議部署到主機。

目前是純前端版本，不含帳號、真實金流、多人連線伺服器與資料庫。若要做成正式線上多人麻將，需要再加入後端 WebSocket、房間配對、會員系統、交易紀錄與防作弊邏輯。
